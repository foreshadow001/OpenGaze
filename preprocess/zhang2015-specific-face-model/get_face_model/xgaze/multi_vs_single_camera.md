# ETH-XGaze 多相机 vs 单相机人脸 3D 模型重建对比实验

**日期** 2026-08-28 ｜ **脚本** [multi_camera_study.py](multi_camera_study.py) ｜ **数据** 80 被试全量（每被试 18 台穹顶相机）
**判据**（与 [EVE 版](../eve/multi_vs_single_camera.md) 一致，用户指定）：建好的 3D 模型投影到像素平面与对应 2d 关键点的误差——各相机**留出测试帧**上 PnP 拟合后的重投影 RMS（中位，px）。

## 1. 问题定义与"不太极端视角"的处理

XGaze 每被试由 18 台相机在穹顶上同时拍摄，视角跨度很大（近正面到极端侧视）。极端视角下关键点检测本身失真，混入实验只会污染结论。**处理方式 = 沿用平台现行建模协议的两级筛选**：

1. **逐视图 <60°**：单帧 PnP 初始头部姿态转角 ≥60° 的视图直接丢弃（更极端视角检测失真）；
2. **相机选择（中位角 <40° 且训练视图 ≥15）**：只有"看脸基本正面"的相机进入实验。80 被试通过 5~13 台（中位 **10** 台）。

**所有实验臂都限定在这同一批选定相机上**，保证各臂输入完全可比（EVE 版中 M 臂额外并入了未通过选择的相机，本版为对称性不再纳入）。S240/S_cross 的源相机 = 每被试中位角最小的相机（最接近正面；EVE 版固定用 basler 的对应物）。

帧采样协议与现行建模一致：跨相机共享的帧宇宙均匀采 120 帧，奇偶分 60 训练 / 60 测试（统一测试集）；S240 的训练帧与测试帧索引距离 >2（防相邻帧泄漏）。内参/畸变逐相机取 `cam_calibration/cam{cc}.xml`。

## 2. 对比的方法详解（各方法怎么做的）

**公共原料**：模型 = 脸上 28 个刚性点（8 眼角 + 20 鼻部，不随表情变形）的三维坐标（mm）；每帧原料 = insightface 检测的 106 个 2D 点中对应 28 个。两个基本操作：**PnP**（已知 3D 模型 + 帧内 2D 点 → 解出该帧头部姿态）与 **BA 联合优化**（同时微调 28 点坐标 + 每帧姿态，使模型投影回图像后与检测点总体最贴——"捏脸"过程）。评估一律在**未参与训练的测试帧**上：模型 PnP 摆位 → 投影 28 点 vs 检测 28 点的 RMS（px，中位）。

| 臂 | 做法（逐步） | 关键特征 |
|---|---|---|
| **S** 单相机逐组（现行方案） | 对每台选定相机：取本相机 60 训练帧 → 逐帧 PnP（拿通用模型当初始参照）→ 三角化粗定位 → 剔一半坏帧 → BA 只用本相机数据 → 交付该相机专属模型 `cam{cc}_model` | 各相机**完全独立**建模，互不知晓；一被试最多 13 个模型 |
| **T** 消融：仅三角化 | 只走到「三角化粗定位」就停：全部 60 帧观测 + PnP 初始姿态 → DLT 求交点得 28 点坐标，**不剔帧、不 BA** | 拆解管线各环节贡献 |
| **Tk** 消融：剔帧后仅三角化 | 同 T，但只用剔除坏帧后的好帧（剔帧判据与 S 完全一致：粗模型回投影残差排序留 50%） | T→Tk→S 逐级归因剔帧与 BA 的贡献 |
| **S240** 视图数对照 | 同 S，但源相机用 240 训练帧（与测试帧索引距离 >2 防泄漏） | 唯一目的：区分「多相机=相机多样性」与「多相机=帧多」两个混淆变量 |
| **F** 模型级融合 | 先完整跑完 S 得到每相机现成模型 → 每个模型整体刚体对齐（Kabsch：两点云间求最优旋转平移，不变形）到源相机模型 → 28 点逐点取中位 → 每被试一个融合模型 | **建模之后**才合并；合并只碰模型不碰观测 |
| **M** 多相机联合 BA | 把全部选定相机（中位 10 台）各自的 60 训练帧倒进同一个池（~600 帧）→ 逐帧照常 PnP 初始化 → BA 优化 {一份共享的 28 点 + 全部 ~600 帧各自姿态} → 每被试一个模型 | **建模之前**观测级共享：10 台相机看到的眼睛被强制是同一组 3D 点，观测同时往这组点上拉；逐相机 f_px 把残差换算到统一像素域 |
| **S_cross** 跨相机考试 | 拿源相机的 S 模型直接考其他选定相机的测试帧（不训练） | 诊断项：单相机模型换相机还灵不灵 |
| **GEN** 通用基线 | 不建模，用 population 平均脸 6 点做 PnP | 参照系：任何方法不超过 GEN 就没有存在价值 |

**方法间区别一句话**：四个建模臂的差别只在「**用哪些帧训练**」和「**3D 点何时被相机间共享**」——S 永不共享；S240 不共享但帧多 4 倍；M 在观测层共享（建模前混数据）；F 在模型层共享（建模后对齐取中位）。

## 3. 结果（80 被试，选定相机集内）

| 臂 | train RMS 中位 | test RMS 中位（px） | 说明 |
|---|---|---|---|
| **S（现行）** | 3.21 | **6.12** | n=768（被试×相机），各相机 3.9~8.8 |
| T（仅三角化） | 5.20 | 6.51 | n=768；已拿到个性化收益的 ~95% |
| Tk（剔帧后三角化） | 3.99 | 6.16 | n=768；剔帧贡献了泛化改善的大头 |
| S240（帧数对照） | 3.68 | 6.45 | n=80；帧多 4 倍无收益 |
| M（多相机联合 BA） | 9.21 | 17.17 | n=768 |
| F（模型级融合） | — | 25.99 | n=768 |
| S_cross（源相机→其他） | — | 36.64 | n=688 |
| GEN（通用基线） | — | 26.33 | n=768 |

- **被试级配对差**：M−S 中位 **+11.06 px**（p90 +23.74），**0% 的（被试，相机）组合 M 优于 S**；F−S 中位 +19.38 px，同样 0%。
- **S 对 GEN 改善 4.2×**——个性化本身收益扎实，但绝对误差远大于 EVE（6.1 vs 0.6 px），主因是尺度与画质：xgaze 相机 fx≈13200（EVE ≈1450），且穹顶红外风格图像的关键点噪声更大。**换算到归一化坐标后两数据集的 S 精度相当**（xgaze 0.46e-3 vs eve 0.41e-3）。
- **S 模型两两结构差异（Kabsch 对齐后，3428 对）**：中位 **5.07 mm**，p90 8.0 mm，最大 19.3 mm——比 EVE（2.3~4.0 mm）更大。同一张脸不可能差 5mm，相机间观测系统性不一致在 xgaze 更严重（18 台相机、视角分布更宽、检测噪声更大）。
- IOD 中位 ~90 mm 各臂正常。

## 4. 差异分析与 EVE 对照

**结论与 EVE 完全一致、幅度更大**：任何形式的跨相机共享都大幅劣化——

1. **S_cross（36.6 px）比 GEN（26.3 px）还差**：源相机建的模型解释其他相机观测的能力还不如通用平均脸，即不同相机"看到的是几何上不同的脸"（结构差异 5mm 级）。
2. **M 的折中代价惨重**：train RMS 从 3.2 升到 9.2 px（EVE 是 0.3→1.1），~600 帧观测互相冲突，BA 只能找一个人人都不满意的解；test 17.2 px 比 GEN 还差 35%。
3. **F 比 M 更差**（26.0 vs 17.2）：Kabsch 对齐 + 逐点中位在 10+ 个互相矛盾的模型间取中位，产物离任何一台相机都很远。
4. **帧数饱和再次确认**：S240=6.45 ≈ S=6.12，60 帧/相机已饱和。
5. **管线消融（T→Tk→S，2026-08-28 补测）**：仅三角化（T=6.51px）已拿到个性化收益的 ~95%（GEN 26.33 → S 6.12 的降幅中，三角化一步完成 6.51/26.33）；**剔坏帧贡献泛化改善的大头**（T→Tk 配对 −0.21px），BA 对留出帧泛化仅再贡献 −0.03px（配对中位）——但 BA 把训练拟合误差从 3.99 压到 3.21px（吸收 PnP 初始姿态的系统误差）。与 EVE 结论一致：结构由多帧线性三角化基本钉死，BA 主要是"精修拟合"而非"改善结构"。噪声大的 xgaze 上剔帧的作用比 EVE 显著（−0.21 vs −0.02px）。
5. **根因同 EVE**：单相机 S 把相机间偏差隔离在各组内（0.4e-3 归一化精度）；跨相机共享（无论观测级 M 还是模型级 F）都被 insightface 检测的相机间系统偏差拖垮。xgaze 偏差更大（5.1 vs 3.3 mm 中位），多相机折中的代价也相应更大（M/S 倍率 2.8× vs EVE 3.1×，绝对值 11.1 vs 1.2 px）。

**两数据集结论互证**：逐相机交付不是工程妥协，而是当前 2D 关键点观测质量下的最优结构。多相机几何约束的收益（视角多样、三角化更稳）远小于相机间观测冲突的代价。
