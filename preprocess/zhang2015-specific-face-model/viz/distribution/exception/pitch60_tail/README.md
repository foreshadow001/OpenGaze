# XGaze Raw Head Pose pitch≈60° 拖尾 — 异常样本归档（2026-09-02）

## 现象

`gaze_distribution_specific.png` 中 xgaze 的 **Head pose (raw)** 行在
pitch≈57–58° 处出现从 yaw≈0 延伸到 yaw≈+100° 的拖尾。

## 归因（16 被试 × 200 帧全量 DLT 实测）

- pitch>45° 的样本 **100% 来自 cam13**（elev +83.4° / azim −127.0°，近正上方），
  占 2.8%；其余 17 台相机零贡献。
- cam13 是穹顶里唯一「近天顶 + 安装滚转使自然姿态读数偏高」的相机：
  自然头姿在 cam13 读 ≈+14°，而仰角同为 ~85° 的 cam05 只读 ≈−3°。
  后仰（下巴抬高）姿态把读数推进 45–60° 区间。
- 拖尾样本的真实姿态：**后仰**——同帧正前方 cam00 读 pitch **+14~+17°**、
  yaw 仅 **+1~+5°**（见下表）。
- **关键观察**：case 02、04–10 是 subject0021 **同一段连续帧**（f0151–f0177）。
  期间物理头姿几乎不变（cam00 pitch 14→17、yaw 2→5，模型 −z 轴仰角仅再降
  ~3°），cam13 的 yaw 读数却从 +16° 扫到 +98°。
  → **拖尾的 yaw 跨度不是物理转头**，而是近极点参数化的放大（量化见下节）。
- 对照组（case 11/12，pitch 33–35）：θ_raw≈63–65°，远离极点，读数正常、
  yaw 稳定在 +13~14°。

**结论**：拖尾是真实数据——「后仰姿态 × cam13 近天顶安装」组合下，极点附近
的 (pitch,yaw) 参数化把微小姿态差放大成 0→90° 的 yaw 扫描。非转换 bug；
但下游若把 raw (pitch,yaw) 当物理量使用，需注意该奇异区
（判据：raw pitch>45° ⇔ cam13 后仰段）。

## 极点放大量化（case 04 = subject0021 f0168）

(pitch, yaw) 是以相机 **y 轴为极点**的球面坐标（pitch=纬度，yaw=经度）。
同一根下颌方向向量 v = ROT·R_head·[0,0,−1]（DLT+Kabsch 的 R_head 与官方
外参复合，与关键点检测无关）：

| | cam13 系 | cam00 系 |
|---|---|---|
| v 分量 | [−0.033, **−0.998**, −0.055] | [−0.045, −0.686, −0.726] |
| 距坐标极点 | **3.6°** | 43°（中纬度） |

- cam13：v 的 99.8% 分量在 y 轴上 → 距极点 3.6°，yaw 是极点邻域的经度，
  对方向实际转动超敏感；cam00：中纬度，yaw 1:1 等于物理 yaw。
- 敏感度（R_head 扰动 +1°）：物理 yaw +1° → cam13 yaw **+8.8°**
  （cam00 +1.0°）；物理 pitch +1° → cam13 yaw **−7.0°**（符号相反），
  cam00 pitch −1.0°。cam13 的 yaw 在此姿态由物理 pitch 反向主导。
- 拖尾段铁证：f0153→f0177 七帧，v 在 cam13 系**实际只转 0.4–3.2°**，
  yaw 读数却从 +89.4° 扫到 +15.7°（74°），pitch 稳在 ~58——方向没动，
  动的是极点附近的经度。放大率 ≈ 74°/3.2° ≈ **23×**。

「cam00 yaw=3.6° 而 cam13 yaw=30.5°」因此不矛盾：同一 3D 方向的两张
2D 坐标卡，一张在极点退化、一张在中纬度正常。任何 2 角参数化都存在
这样的奇异方向（球面无全局连续 2 角坐标卡）。

## cam13 外参（官方 cam13.xml；图上标注为右下角的人类可读形式）

```
欧拉角（extrinsic xyz，R = Rz(γ)·Ry(β)·Rx(α)，固定轴 x→y→z）：
  alpha = −43.6°   beta = −3.3°   gamma = +0.6°
相机位置（世界系，−Rᵀt）：
  pos = [−78, +838, +59] mm   →  elev +83.4° / azim −127.0°（近正上方、偏左前）
```

参考矩阵原值：

```
R = [+0.9983 +0.0324 -0.0480]
    [+0.0096 +0.7242 +0.6895]
    [+0.0571 -0.6888 +0.7227]
t = [+53.4 -646.5 +539.1] mm
```

alpha=−43.6°（绕世界 x 轴）主导整个旋转：把相机从「水平朝前」翻成
「向下俯视 44°」。R 第二行（相机 y 轴/图像向下方向）在世界系指向
[0.01, 0.72, 0.69]（上+前，与竖直夹 ~44°）——近天顶相机的这个滚转朝向
正是 raw pitch 读数偏高的几何根源。

## 数据链路（与 gaze_distribution.py 的 HEAD_RAW 同口径）

v1 特征点（`ylx/xgaze_insightface_224` h5）→ 前 10 相机 undistortPoints +
DLT（官方外参）→ Kabsch(true6_canonical) 得 R_head → 各相机
`rvec = Rodrigues(ROT @ R_head)` → `vector_to_angles(rvec 轴系 @ [0,0,−1])`
− 30°（**无解缠绕**；多相机 raw 帧的 |yaw|>90° 是相机位置所致，解缠绕会
把数据折回主域产生假拖尾——见 gaze_distribution.py 注释）。
